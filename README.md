# umair.github.io

Personal portfolio website for Umair Ahmed — AI & Automation Engineer.

## Tech Stack

- React 19
- Vite 6
- CSS3 (custom properties, animations)

## Design

- Brutalist minimal developer aesthetic
- Dark black theme with orange accent
- JetBrains Mono + Syne typography
- Custom cursor, noise texture, scroll animations

## Development

```bash
npm install
npm run dev
```

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions on every push to `main`.
